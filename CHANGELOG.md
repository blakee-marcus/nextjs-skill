## [0.1.12] - 2026-10-03

- Version-aware operational guidance for App Router, Pages Router, Cache Components, Server Actions, Turbopack, testing, deployment, and migration.

- Public-surface verification, packaging checks, and GitHub Actions CI.

- Refocused the README on installed-version detection, evidence, and the smallest verified fix.
- Clarified maintained runtime evidence and separated installer support from runtime compatibility.
